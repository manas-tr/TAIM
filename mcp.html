Quickstart Setup

Remote OAuth

Taim runs as a remote Streamable HTTP MCP server. No local binaries or Python packages needed. Run the one-line setup in your terminal: 

claude mcp add --transport http taim https://mcp.trytaim.com/mcp

Next, launch Claude Code and type /mcp. Select taim, complete the browser sign-in with your Taim account, and start asking:

"Use Taim to show my recent marketing ideas thread, then help me draft the carousel script."

Authentication & Security

Non-destructive

Sign in with your standard Taim account via OAuth 2.0. All 7 tools are strictly non-destructive. There are no delete, archive, or task destructive permissions exposed. You can disconnect at any time from your client settings.

list_threads Read Tool

List threads you own and threads shared with you, ordered by most recent activity. Ideal for browsing or resolving thread IDs.

Parameter Type Description
limit integer Maximum threads to return (1–100, default: 20).
include_archived boolean Whether to include archived threads (default: false). 
// Example Call
{
  "name": "list_threads",
  "arguments": { "limit": 5, "include_archived": false }
}
search_threads Read Tool

Search owned and shared threads by meaning and keywords. Ask natural-language questions even if you do not remember exact thread titles.

Parameter Type Description
queryRequired string Natural language query or keywords.
limit integer Maximum matching results (1–100). 
// Example Call
{
  "name": "search_threads",
  "arguments": { "query": "What are our weekly goals?", "limit": 3 }
}
get_thread Read Tool

Read one thread with recent entries, open tasks, and collaborators. Pass a thread ID obtained from list_threads or search_threads.

Parameter Type Description
thread_idRequired string UUID of the thread to retrieve.
entry_limit integer Maximum entries to return (1–100). 
// Example Call
{
  "name": "get_thread",
  "arguments": {
    "thread_id": "0d19e8bf-6a5c-4c97-93f8-a20657e16b72",
    "entry_limit": 10
  }
}
search_memories Read Tool

Search your personal Taim memory graph for facts, preferences, and recurring context across conversations.

Parameter Type Description
queryRequired string Description of personal facts or recall items.
limit integer Maximum results (1–50).
pull_context Read Tool

Single-call aggregator that searches threads and personal memories simultaneously, returning a unified synthesized context window.

create_thread Write Tool

Create a new living thread in Taim with a title, category kind, and optional initial note.

Parameter Type Description
titleRequired string Name of the new thread.
thread_kind string Category (work, creative, travel, life, personal).
initial_content string Optional first entry or note.
add_thread_entry Write Tool

Append a new note, decision, code snippet, or action item into an existing thread.

Parameter Type Description
thread_idRequired string UUID of target thread.
contentRequired string Markdown note content or task body.
title string Optional entry heading.
